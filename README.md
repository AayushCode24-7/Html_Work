🚀 HTML Practice: My Digital Sandbox
Welcome to the HTML Practice repository! This is where I stop being a mere "user" of the internet and start building it—one tag at a time. Whether I’m wrestling with a <div> that won't centre or discovering the magic of a <marquee> (yes, I know it’s 2026, but let me live), this is where the magic happens.

🛠️ What's Inside?
This repo is a collection of my experiments, failures, and "AHA!" moments. It covers the essentials of building for the web:

Semantic Structure: Learning why <header>, <main>, and <footer> are better than a "div-soup."

Forms & Inputs: Creating ways for users to talk back (and making sure those submit buttons actually look clickable).

Media Embedding: Figuring out how to stick images, videos, and those "slightly annoying" auto-play audios into a page.

Table Torture: Mastering the art of <tr> and <td> without losing my mind.

🧠 Why This Exists
I believe in the "Break it to Make it" philosophy.

"Code is like humor. When you have to explain it, it’s bad." – Cory House

My goal here isn't just to write code that works, but to write code that makes sense. I'm practicing how to structure content so that both humans and screen readers can navigate my creations with ease.
